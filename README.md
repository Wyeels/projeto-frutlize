<p>Primeiro projeto "grande" criado, feito para simular um hortifruti online</p>

<h2>Funcionalidade:</h2>
<p>O projeto funciona de maneira simples, por ter sido o primeiro projeto feito, muitas coisas são ilustrativas, como o carrinho de compras e tela de login. Nele, você poderia comprar seus legumes e frutas de forma totalmente online e receber em sua casa. <br>
O projeto também inclui um simples sistema de responsividade, funcionando corretamente em quaisquer dispositivos, porém de forma mais simples.</p>
